# Fran Jurmanović - Portfolio

A unique portfolio site where visitors tune into radio frequencies to unlock content. Built with Next.js.

## What is this?

This is my personal portfolio website with a twist. Instead of a boring static page, visitors get to experience finding my information like they're tuning an old radio. Each section of my portfolio is hidden on different frequencies that users need to discover. Of course, I am not a cryptographer so everything "cyphered" content can be easily found using devtools.

## How it works

### Radio UI
The main page presents a digital radio tuner interface. Visitors drag a frequency dial to scan through different MHz values:
- Most frequencies = static and scrambled text
- Getting warmer = text starts to become readable
- Perfect frequency = clear signal, full content revealed

Different frequencies unlock different sections that read something about me or my projects.

The experience includes audio feedback - static noise that clears up as you find the right frequency, with a satisfying "lock-on" sound when you nail it.

### Simple UI
Regular content for people in hurry. Offers better UX.

## Why?

I had this idea for some time. I wanted something creative to replace my old "simple" (boring) portfolio site and display the experience I have gained throughout my career.
